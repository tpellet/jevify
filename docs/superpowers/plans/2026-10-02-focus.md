# Focus pass: why and fill first (0.14.2 → 0.15.0)

Source: Fable marketing review and Opus cross-review of 0.14.2, and the MCP connector study
(2026-10-01). Owner approved all items 2026-10-02. Publishing to outside channels stays with the
owner.

`fill` in one sentence: write the command; where an ID goes, describe it in `@{…}`; jevify puts in
the real ID or runs nothing.

## Tasks

F1. Key sign-up path. The TypeSafe sign-up URL appears in the `quota_exhausted` hint, in `health`
    output, and in the Action's job summary when jevify exits 4. Contract test on the hint.
F2. Triage in the Action. Optional `classes:` input (e.g. `compile|test|flaky|infra`) runs
    `fill --context <log> … '@{one:…}'` or equivalent on the same log and writes the class next to
    the line. Hand-label the 34 why-ci logs into `benchmarks/` and report accuracy, abstain, wrong.
F3. "Run the test I mean" recipe. In `jevify init agents` and the plugin SKILL.md. Gold set of 50
    behaviours over this repo's tests and one pinned repo, scored on hit / abstain / wrong-and-run,
    in `benchmarks/`.
F4. Hook without `jq`. The binary prints the Claude Code hook JSON itself (a `why` flag or similar);
    `plugins/jevify/hooks/why-on-fail.sh` shrinks to a thin wrapper. Document the Codex path.
F5. `jevify mcp`: stdio MCP server, hand-rolled JSON-RPC (initialize, tools/list, tools/call), no
    new crate. Tools: `why` (path or text), `is`, `pick` (select only; items or from_kind). Abstain
    is a successful result with the shortlist. Updates cli.rs, dispatch, capabilities(),
    ROBOT_MODE, PRIVACY row, plugin `mcpServers`, a Claude Desktop .mcpb manifest, Codex snippet,
    contract tests (tests/mcp.rs with FakeJev) and one live e2e case.
F6. Narrow the surface. Fold `label` into `filter --label a,b,c` (drop the `label` verb); move
    `add` out of the README first screen and core docs (the verb stays).
F7. README and docs. First screen: `why` with 30/34 vs 11/34, one `fill` line using a supplied
    test list, the one-sentence model. Label the demo's backend ("windows 13" is keyless), mark
    placeholder examples, remove token/byte-saving claims ("424×", "99.76%") and "grep for
    meaning", add latency, error hints, the `is` claim-check pattern, MCP install. Rerun
    `tests/transcripts.rs`.
F8. Gate and release 0.15.0: full gate, live e2e, transcripts, CHANGELOG.

Order: F1, F2, F3, F4, F5 in parallel (reserve shared files such as `src/cmd/agent.rs`,
`src/cli.rs`, `action.yml` before editing; wait on a conflict). F6 after F5. F7 after all code.
F8 last.
